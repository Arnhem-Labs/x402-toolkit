# Security Policy

If you discover a security vulnerability in this project, please report it
privately to **security@arnhemlabs.com** rather than opening a public issue.

We aim to acknowledge reports within 72 hours and to publish a fix or
mitigation within 14 days for confirmed issues.

This project handles payment-related code paths and depends on cryptographic
primitives in third-party crates; please include reproduction steps and an
indication of severity in your report.
